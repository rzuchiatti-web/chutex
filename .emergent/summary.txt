- **State-Driven UI**: Complex pages like Interventions/Prescriptions/Alerts have multiple states (inactive, active, detail view, report view) all handled within a single component file using state variables and conditional rendering.
- **React Native Web Component Adaptation**: Converting user-provided HTML/CSS/JS (from their website) into functional React Native for Web components, including complex CSS animations (typewriter, scan effects).
